# 🎨 LogicCraft — UML Редактор и Генератор Кода

Профессиональный визуальный редактор UML диаграмм классов с автоматической генерацией кода на 5 языках программирования.

## ✨ Возможности

### Редактор диаграмм
- 🃏 **4 типа UML элементов** — Класс, Абстрактный класс, Интерфейс, Перечисление (Enum) с визуальным отличием
- 🔗 **6 типов связей** — Ассоциация, Наследование, Композиция, Агрегация, Зависимость, Реализация
- 📐 **Свойства связей** — множественность (1, 0..1, 0..*, 1..*) и имена ролей
- 🧰 **Левая панель (Toolbox)** — быстрое добавление элементов и выбор типа связи
- 📋 **Правая панель (Properties)** — редактирование свойств без диалогов
- ↩️ **Undo/Redo** — неограниченная история изменений
- 🖱️ **Двойной клик** — быстрое редактирование класса
- ⌨️ **Inline-редактирование (F2)** — переименование без диалога
- 🔍 **Поиск классов (Ctrl+F)** — fuzzy-поиск с автоцентрированием
- 💡 **Подсветка связей** — автоматическое выделение связанных элементов

### Навигация
- 🖱️ **Панорамирование** — средняя кнопка мыши или Пробел + drag
- 🔍 **Масштабирование** — Ctrl + колесо, кнопки в статусбаре
- 📏 **Snap to grid** — автоматическая привязка к сетке
- ⊡ **Fit to screen** — вписать диаграмму в экран (Ctrl+F)

### Валидация и анализ
- ✅ **Улучшенная валидация (Ctrl+Shift+V)** — категоризация проблем, рекомендации
- 📊 **Экспорт отчётов** — сохранение результатов валидации в TXT/HTML
- 🔍 **Проверка циклов** — обнаружение циклических зависимостей
- ⚠️ **Система предупреждений** — ошибки, предупреждения, информация

### Генерация кода
- 🚀 **2 языка** — Python, Java
- 🎨 **Улучшенный UI выбора языков** — radio buttons с иконками
- 📝 **Настраиваемые шаблоны** — менеджер пользовательских шаблонов Jinja2
- 📦 **Экспорт проекта** — готовая структура папок с конфигурационными файлами
- 🏗️ **Архитектурные шаблоны** — Simple, MVC, Layered, Clean Architecture
- ⚙️ **Опции генерации** — документация, типизация, один файл/раздельные файлы

### Use Case диаграммы
- 👤 **Актёры и сценарии** — визуализация человечков и овалов
- 🔄 **Переключатель типов** — быстрое переключение между классами и Use Case
- 🏷️ **Стереотипы** — метки «include» и «extend» на связях
- ✅ **Валидация Use Case** — проверка корректности диаграмм

### Интерфейс
- 🏠 **Welcome Screen** — стартовое окно при запуске
- 🎨 **Современная тема** — фиолетовая цветовая схема
- 💾 **Сохранение/загрузка** — формат JSON

## 🚀 Быстрый старт

### Запуск из исходников

```bash
git clone https://github.com/yourusername/logiccraft.git
cd logiccraft
poetry install
poetry run python -m logiccraft
```

### 🍎 Сборка .app для macOS

Для создания полноценного macOS приложения с автоматическими разрешениями:

```bash
# Установить зависимости для сборки
poetry add --group dev py2app

# Собрать приложение
./build_macos.sh

# Создать DMG для распространения
./create_dmg.sh
```

Подробнее см. [docs/MACOS_PERMISSIONS.md](docs/MACOS_PERMISSIONS.md)

## 📋 Системные требования

- **Python**: 3.13+
- **ОС**: Windows 10+, macOS 11+, Linux (Ubuntu 20.04+)
- **RAM**: 512 MB
- **Дисплей**: 1280x720+

### 🍎 Дополнительно для macOS

На macOS приложению требуются разрешения для доступа к файловой системе. Подробнее см. [docs/MACOS_PERMISSIONS.md](docs/MACOS_PERMISSIONS.md)

**Рекомендуемый способ:** При создании проекта используйте кнопку "Обзор" — это автоматически даст приложению доступ к выбранной папке через системный диалог.
