## 🛠 Гайд по разработке (Developer Guide)

### 1. Архитектура данных (Семён)
* **UMLNode:** содержит `id`, `name`, `x`, `y`, `properties[]`, `methods[]`.
* **UMLConnection:** содержит `source_id`, `target_id`, `type`, `multiplicity`.
* **Важно:** Использовать `uuid.uuid4()` для ID, чтобы избежать дублей.

### 2. Визуальные стандарты (Даша)
* **Координаты:** Всегда используем `e.local_position.x` и `y`.
* **Верстка:** Карточка класса — это `ft.Container` с `ft.Column` внутри. Разделять секции через `ft.Divider`.
* **Кратность:** Отображать текст кратности (1..*) рядом с наконечником стрелки.

### 3. Правила кроссплатформенности (Саша)
* **Пути:** Только `pathlib.Path`. Никаких строк с обратными слэшами.
* **Синтаксис:** Использовать `ft.run(main)` и `ft.Alignment(0, 0)`.
* **Кодировка:** Все `.json` и `.py` сохраняются строго в **UTF-8**.

## 🚀 Быстрый старт
1. Установить Poetry и Python 3.13.
2. Выполнить `poetry install`.
3. Запустить проект: `poetry run python src/logiccraft/main.py`.
