# 🎨 LogicCraft - UML Диаграммы и Генерация Кода

Создавайте UML диаграммы классов визуально и автоматически генерируйте код на Python, Java, JavaScript.

![LogicCraft Screenshot](docs/images/screenshot.png)

## ✨ Основные возможности

- 📊 **Визуальный редактор** — создавайте UML диаграммы классов перетаскиванием
- 🔗 **Умные связи** — наследование, композиция, ассоциация, агрегация
- ✏️ **Редактирование** — добавляйте атрибуты и методы через удобные диалоги
- 💾 **Сохранение** — диаграммы сохраняются в JSON формате
- 🚀 **Генерация кода** — автоматическое создание кода на 5 языках (Python, Java, JavaScript, TypeScript, C#)
- 📦 **Экспорт проекта** — создание готовой структуры папок проекта на диск с конфигурационными файлами, тестами и документацией
- ⚡ **Undo/Redo** — отмена и повтор действий с умной оптимизацией
- 🎨 **Современный UI** — темная/светлая тема, сетка, точки привязки

## 🚀 Быстрый старт

```bash
# Клонирование репозитория
git clone https://github.com/yourusername/logiccraft.git
cd logiccraft

# Установка зависимостей
poetry install

# Запуск приложения
poetry run python -m src.logiccraft.main
```

## 📋 Системные требования

- **Python**: 3.13+
- **ОС**: Windows 10+, macOS 11+, Linux (Ubuntu 20.04+)
- **RAM**: 512 MB
- **Дисплей**: 1280x720+

## 🎯 Как использовать

1. **Создайте класс** — нажмите "Add Class" или дважды кликните на пустом месте
2. **Редактируйте класс** — кликните правой кнопкой → "Edit" или дважды кликните по карточке
3. **Создайте связь** — перетащите от красной точки одного класса к другому
4. **Сохраните диаграмму** — File → Save или Ctrl+S
5. **Генерируйте код** — выберите язык и нажмите "Generate Code" (Ctrl+G)
6. **Экспортируйте проект** — Tools → Export Project (Ctrl+E) для создания готовой структуры папок
