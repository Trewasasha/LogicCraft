# 📋 История изменений LogicCraft

Все значимые изменения в проекте LogicCraft документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и проект следует [Semantic Versioning](https://semver.org/lang/ru/).

### Добавлено (предыдущие версии)
- 🎨 Система шаблонов Jinja2 для генерации кода
- 📝 Поддержка 5 языков программирования: Python, Java, JavaScript, TypeScript, C#
- ⚙️ Конфигурационная система для настройки генерации кода (`templates/config.py`)
- 📋 Метод `generate_files()` для создания отдельных файлов классов
- 🔄 Автоматическая обработка связей наследования в генерируемом коде
- 📚 Документация по системе генерации кода (`docs/CODE_GENERATION.md`)
- 🚀 **UI для генерации кода** — кнопка в тулбаре и меню Tools (Ctrl+G)
- 💻 **Диалог генерации кода** с предпросмотром, подсветкой синтаксиса и экспортом
- 📊 **Статистика генерации** — информация о файлах, строках и классах
- 💾 **Экспорт в файлы** — сохранение сгенерированного кода в выбранную папку
- Контекстное меню для UML карточек (правый клик → Edit/Delete)
- Улучшенные стили для диалогов и меню
- Константы стилей в theme.py для диалогов и меню
- Подробная документация по стилизации в STYLING.md
- 📦 **Экспорт структуры проекта** — полноценный экспорт UML диаграммы как готового проекта на диск (меню Tools → Export Project, Ctrl+E)
- 🗂️ **ProjectExportDialog** — диалог с 4 вкладками: основные настройки, стиль кода, дополнительные файлы, предпросмотр структуры
- 🏗️ **Шаблоны архитектур** — Simple, MVC, Layered Architecture, Clean Architecture для всех 5 языков
- ⚙️ **Настройки генерации кода** — отступы, соглашения именования (camelCase/snake_case/PascalCase), конструкторы, геттеры/сеттеры, docstrings, type hints
- 📄 **Генерация конфигурационных файлов** — requirements.txt / pyproject.toml, pom.xml, package.json, tsconfig.json, .csproj / .sln
- 🔧 **Дополнительные файлы** — README.md, .gitignore (языко-специфичный), тесты, docs/, LICENSE, GitHub Actions CI
- 👁️ **Предпросмотр структуры** — дерево файлов обновляется в реальном времени при изменении настроек
- 🔄 **Фоновый экспорт** — прогресс-бар, экспорт выполняется в отдельном потоке без блокировки UI
- 🎨 **Новая тема оформления** — фиолетовая цветовая схема (#7C3AED), светло-лавандовый фон (#F0EFFE), скруглённые карточки
- 🃏 **Визуальное отличие типов UML** — интерфейсы (◇ светло-фиолетовый), enum (≡ зелёный), абстрактные классы (△ средне-фиолетовый), стереотипы «interface»/«enumeration»/«abstract»
- 🖊️ **Расширенный диалог редактирования** — выбор типа узла (класс/интерфейс/enum/абстрактный), отдельная секция для enum-литералов
- 🏠 **Welcome Screen** — стартовое окно при запуске с кнопками "Открыть проект" и "Создать новый проект", адаптивный размер кнопок
- 📦 **`__main__.py`** — поддержка запуска через `python -m logiccraft`
- 📖 **docs/UML_TYPES.md** — документация по всем типам UML элементов с примерами кода
- 🧰 **Левая панель (Toolbox)** — типы элементов (Класс, Абстрактный, Интерфейс, Enum) и типы связей
- 📋 **Правая панель (Properties)** — свойства выбранного элемента: имя, тип, атрибуты, методы, удаление
- 📊 **Статусбар** — показывает количество классов и связей в реальном времени
- 🔗 **Dependency и Realization** — пунктирные линии с соответствующими наконечниками
- 📐 **Свойства связей** — множественность (1, 0..1, 0..*, 1..*) и имя связи с отображением на диаграмме
- 🔍 **Навигация** — панорамирование средней кнопкой мыши и Пробел+drag, zoom Ctrl+колесо
- 📏 **Snap to grid** — автоматическая привязка элементов к сетке
- 🔢 **Индикатор масштаба** — кнопки zoom в статусбаре (−, %, +, ⊡, 1:1)
- ⌨️ **Горячие клавиши zoom** — Ctrl+=, Ctrl+-, Ctrl+0, Ctrl+F
- 📋 **Копирование/вставка** — Ctrl+C / Ctrl+V для карточек классов
- ⧉ **Дублирование** — Ctrl+D создаёт копию выбранного класса
- ⬜ **Выделить всё** — Ctrl+A
- 🖼️ **Экспорт PNG/SVG** — Ctrl+Shift+E, высокое разрешение

### Изменено
- 🔧 Полностью переписан `CodeGenerator` с использованием Jinja2 вместо строковой конкатенации
- 📁 Реорганизована структура шаблонов в отдельную папку `templates/`
- 🎯 Улучшена архитектура генерации кода для лучшей расширяемости
- Улучшен диалог редактирования класса (лучшие отступы, размеры)
- Реструктурирована документация (README.md, USER_GUIDE.md, DEVELOPER_GUIDE.md, ARCHITECTURE.md)
- 🎨 Тулбар переработан — три pill-кнопки справа ("Сохранить диаграмму", "Загрузить диаграмму", "Сгенерировать код")
- 🐛 Исправлены шаблоны Python/Java — корректное сравнение `node_type.value`
- 🔌 Контекстное меню карточек переведено на русский язык
- 🔗 `ConnectionType` enum расширен: `dependency`, `realization`, `interaction`
- 📐 Сигнал `add_card_requested` передаёт `node_type` для корректного создания типов

### Добавлено
- **HistoryService** — продвинутая система Undo/Redo с оптимизациями
- Поддержка сохранения позиций карточек при Undo/Redo
- Сохранение изменений атрибутов/методов в истории
- 3-уровневая система валидации состояний
- Сжатие старых состояний для экономии памяти
- Потокобезопасность через threading.Lock
- Дедупликация одинаковых состояний

### Изменено
- **КРИТИЧНО**: Исправлена дедупликация состояний (сравнение по ID вместо индекса)
- **КРИТИЧНО**: Разделена блокировка для минимизации времени под lock
- Использование Pydantic model_copy() вместо copy.deepcopy() (+30-50% производительности)
- Оптимизирован алгоритм сжатия (in-place удаление без копий)

### Исправлено
- Исправлено дублирование ArrowHead при создании связей
- Карточки теперь сохраняют позицию при Undo/Redo
- Изменения атрибутов/методов сохраняются в истории
- Устранены утечки памяти в HistoryService
- Исправлены race conditions в многопоточной среде

### Производительность
- Копирование состояния: +30-50% быстрее
- Валидация: -96% проверок при обычных операциях
- Память при drag&drop: -94% состояний
- CPU нагрузка при перетаскивании: -90%
- Время блокировки: -95%

## [1.2.0] - 2024-04-15

- Централизованная система стилей в theme.py и style.qss
- Поддержка светлой и темной тем

## [1.1.0] - 2024-04-10

### Добавлено
- Базовая функциональность создания UML диаграмм
- Поддержка классов с атрибутами и методами
- Связи между классами (Association, Inheritance, Composition, Aggregation)
- Сохранение и загрузка диаграмм в JSON

### Технические детали
- Архитектура MVC с PyQt6
- Pydantic модели для валидации данных

- Система сигналов/слотов для коммуникации
