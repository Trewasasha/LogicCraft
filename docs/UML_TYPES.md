# Типы UML элементов в LogicCraft

LogicCraft поддерживает 4 типа UML элементов с визуальным отличием:

## 1. Обычный класс (Class)

**Визуальные признаки:**
- Иконка: ⬡ (шестиугольник)
- Цвет заголовка: Фиолетовый `#7C3AED`
- Стиль имени: Обычный жирный шрифт
- Без стереотипа

**Пример:**
```
┌─────────────────┐
│  ⬡ User         │ ← Фиолетовый заголовок
├─────────────────┤
│ - id: number    │
│ - name: string  │
├─────────────────┤
│ + login(): void │
└─────────────────┘
```

**Генерация кода (Python):**
```python
class User:
    """Class generated from UML diagram"""
    
    id: int
    name: str
    
    def __init__(self):
        self.id = None
        self.name = None
    
    def login(self) -> None:
        pass
```

## 2. Абстрактный класс (Abstract Class)

**Визуальные признаки:**
- Иконка: △ (треугольник)
- Цвет заголовка: Средне-фиолетовый `#8B5CF6`
- Стиль имени: **Курсив + жирный**
- Стереотип: `«abstract»`

**Пример:**
```
┌─────────────────┐
│  «abstract»     │
│  △ Shape        │ ← Средне-фиолетовый, курсив
├─────────────────┤
│ - color: string │
├─────────────────┤
│ + draw(): void  │ ← Абстрактный метод
└─────────────────┘
```

**Генерация кода (Python):**
```python
from abc import ABC, abstractmethod

class Shape(ABC):
    """Abstract class: Shape"""
    
    color: str
    
    def __init__(self):
        self.color = None
    
    @abstractmethod
    def draw(self) -> None:
        raise NotImplementedError
```

---

## 3. Интерфейс (Interface)

**Визуальные признаки:**
- Иконка: ◇ (ромб)
- Цвет заголовка: Светло-фиолетовый `#9B72F5`
- Стиль имени: **Курсив + жирный**
- Стереотип: `«interface»`

**Пример:**
```
┌─────────────────┐
│  «interface»    │
│  ◇ Drawable     │ ← Светло-фиолетовый, курсив
├─────────────────┤
│ + draw(): void  │ ← Все методы абстрактные
│ + resize(): void│
└─────────────────┘
```

**Генерация кода (Python):**
```python
from abc import ABC, abstractmethod

class Drawable(ABC):
    """Interface: Drawable"""
    
    @abstractmethod
    def draw(self) -> None:
        raise NotImplementedError
    
    @abstractmethod
    def resize(self) -> None:
        raise NotImplementedError
```

**Генерация кода (Java):**
```java
public interface Drawable {
    void draw();
    void resize();
}
```

## 4. Перечисление (Enum)

**Визуальные признаки:**
- Иконка: ≡ (три горизонтальные линии)
- Цвет заголовка: Зелёный `#10B981`
- Стиль имени: Обычный жирный шрифт
- Стереотип: `«enumeration»`

**Пример:**
```
┌─────────────────┐
│ «enumeration»   │
│  ≡ Status       │ ← Зелёный заголовок
├─────────────────┤
│ ACTIVE          │
│ INACTIVE        │
│ PENDING         │
└─────────────────┘
```

**Генерация кода (Python):**
```python
from enum import Enum

class Status(Enum):
    """Enumeration: Status"""
    
    ACTIVE = 1
    INACTIVE = 2
    PENDING = 3
```

**Генерация кода (Java):**
```java
public enum Status {
    ACTIVE,
    INACTIVE,
    PENDING;
}
```

## Как создать элемент нужного типа

### При создании нового класса:
1. Нажмите "➕ Добавить класс" в тулбаре
2. Класс создаётся как обычный (Class) по умолчанию
3. Кликните правой кнопкой → "✏ Редактировать класс"
4. В диалоге выберите нужный тип из выпадающего списка "Тип:"

### При редактировании существующего:
1. Выберите карточку на диаграмме
2. Нажмите "✏️ Редактировать" в тулбаре или правой кнопкой → "✏ Редактировать класс"
3. Измените тип в выпадающем списке "Тип:"
4. Нажмите OK

### Особенности редактирования Enum:
- При выборе типа "Перечисление (Enum)" интерфейс меняется
- Вместо атрибутов и методов показывается список "Значения (литералы)"
- Добавляйте значения в формате: `RED` или `RED = 1`

## Визуальная шпаргалка

| Тип | Иконка | Цвет заголовка | Стиль имени | Стереотип |
|-----|--------|----------------|-------------|-----------|
| **Class** | ⬡ | Фиолетовый `#7C3AED` | Обычный | — |
| **Abstract** | △ | Средне-фиолетовый `#8B5CF6` | *Курсив* | `«abstract»` |
| **Interface** | ◇ | Светло-фиолетовый `#9B72F5` | *Курсив* | `«interface»` |
| **Enum** | ≡ | Зелёный `#10B981` | Обычный | `«enumeration»` |

## Генерация кода

Все типы корректно генерируются в код для поддерживаемых языков:

- **Python** — использует `ABC`, `abstractmethod`, `Enum`
- **Java** — генерирует `interface`, `abstract class`, `enum`
- **TypeScript** — генерирует `interface`, `abstract class`, `enum`
- **C#** — генерирует `interface`, `abstract class`, `enum`
- **JavaScript** — эмулирует интерфейсы через комментарии

---

## Связи между типами

- **Наследование (Inheritance)** — класс наследует от класса или абстрактного класса
- **Реализация (Realization)** — класс реализует интерфейс
- **Композиция/Агрегация** — любые типы могут участвовать

Визуально связи отображаются стрелками разных типов (см. документацию по связям).
