# 🗺️ Дорожная карта LogicCraft

Планы развития проекта LogicCraft на ближайшие версии и долгосрочную перспективу.

## 📍 Текущая версия: v1.4.0-dev

### Прогресс: Недели 1–8 выполнены ✅ | Следующий шаг: Неделя 9 (Валидация и дополнительные языки)

### ✅ Реализовано
- Базовый редактор UML диаграмм
- Создание и редактирование классов
- Связи между классами (Association, Inheritance, Composition, Aggregation, **Dependency, Realization**)
- Сохранение/загрузка в JSON
- **Генерация кода (Python, Java, JavaScript, TypeScript, C#) с полным UI**
- **Диалог генерации кода с предпросмотром и экспортом**
- **Экспорт структуры проекта на диск** — диалог с настройками архитектуры, стиля кода, конфигурационных файлов и предпросмотром (Ctrl+E)
- Система Undo/Redo с оптимизациями
- Контекстное меню для классов (русский язык)
- Централизованная система стилей (theme.py + style.qss)
- **Новая фиолетовая тема** — полный редизайн UI по макету Figma
- **Типы UML элементов** — интерфейсы, enum, абстрактные классы с визуальным отличием
- **Welcome Screen** — стартовое окно при запуске приложения
- **Запуск через `python -m logiccraft`**
- **Левая панель (Toolbox)** — быстрое добавление элементов и выбор типа связи
- **Правая панель (Properties)** — редактирование свойств выбранного элемента без диалогов
- **Свойства связей** — множественность (1, 0..1, 0..*, 1..*) и имена ролей
- **Навигация** — панорамирование средней кнопкой и Пробел+drag, zoom Ctrl+колесо
- **Snap to grid** — автоматическая привязка к сетке
- **Индикатор масштаба** — кнопки zoom в статусбаре
- **Копирование/вставка/дублирование** — Ctrl+C / Ctrl+V / Ctrl+D
- **Выделить всё** — Ctrl+A
- **Экспорт PNG/SVG** — Ctrl+Shift+E, высокое разрешение
- **Групповые операции** — перемещение, удаление нескольких элементов одновременно
- **Выравнивание элементов** — 6 вариантов (по краям и по центру)
- **Валидация UML** — Ctrl+Shift+V, проверка дублей, циклов, пустых классов
- **Поиск классов (Ctrl+F)** — быстрый поиск с fuzzy-поиском и автоцентрированием
- **Подсветка связанных классов** — автоматическое выделение связанных элементов при выборе
- **Мини-карта диаграммы** — навигация по большим диаграммам с viewport overlay
