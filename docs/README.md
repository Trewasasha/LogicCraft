## 🤝 Участие в документации

Документация — это живой проект, который постоянно улучшается. Вы можете помочь:

### Как внести вклад

1. **Нашли ошибку?** — создайте Issue с описанием проблемы
2. **Хотите улучшить?** — создайте Pull Request с изменениями
3. **Нужна новая тема?** — предложите в Discussions

### Стандарты документации

- **Язык**: русский для пользовательской документации, английский для технической
- **Формат**: Markdown с эмодзи для навигации
- **Структура**: заголовки, списки, примеры кода
- **Стиль**: дружелюбный, понятный, с практическими примерами

### Шаблон для новых документов

```markdown
# 📝 Название документа

Краткое описание содержания документа.

## Содержание

1. [Раздел 1](#раздел-1)
2. [Раздел 2](#раздел-2)

## Раздел 1

Содержание раздела с примерами.

### Подраздел

Детальная информация.

## Заключение

Краткое резюме и ссылки на связанные документы.
```
