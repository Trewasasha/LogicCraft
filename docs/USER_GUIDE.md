## Запуск

```bash
poetry run python -m logiccraft
```

При запуске откроется **Welcome Screen** с двумя вариантами:
- **Открыть проект** — загрузить существующую диаграмму (.json)
- **Создать новый проект** — начать с чистого листа

## Интерфейс

```
┌─────────────────────────────────────────────────────────────────┐
│  [Тулбар: Добавить | Редактировать | Удалить | Связи | Очистить]│
│  [Сохранить диаграмму] [Загрузить диаграмму] [Сгенерировать код]│
├──────────────┬──────────────────────────────┬───────────────────┤
│              │                              │                   │
│  Toolbox     │       Холст (Canvas)         │   Properties      │
│              │                              │                   │
│  Элементы:   │   Здесь размещаются          │  Свойства         │
│  ⬡ Класс     │   UML карточки и связи       │  выбранного       │
│  △ Абстракт. │                              │  элемента         │
│  ◇ Интерфейс │                              │                   │
│  ≡ Enum      │                              │  Имя, Тип,        │
│              │                              │  Атрибуты,        │
│  Связи:      │                              │  Методы           │
│  → Ассоц.    │                              │                   │
│  ▷ Наслед.   │                              │                   │
│  ...         │                              │                   │
├──────────────┴──────────────────────────────┴───────────────────┤
│  Ready  |  Классов: 3  |  Связей: 2  |  [−] [100%] [+] [⊡] [1:1]│
└─────────────────────────────────────────────────────────────────┘
```

### Панели

**Левая панель (Toolbox)** — клик на кнопку добавляет элемент в центр холста:
- Секция "Классы" — 4 типа UML элементов
- Секция "Связи" — 6 типов связей (применяется к выбранной связи или устанавливается для следующей)

**Правая панель (Properties)** — показывается при выборе элемента:
- Редактирование имени в реальном времени
- Смена типа узла
- Добавление/удаление атрибутов и методов
- Кнопка удаления

**Статусбар** — информация и управление масштабом:
- Количество классов и связей
- Кнопки zoom: `−`, `%`, `+`, `⊡` (fit), `1:1` (reset)

## Типы элементов

| Тип | Иконка | Цвет заголовка | Стереотип |
|-----|--------|----------------|-----------|
| Класс | ⬡ | Фиолетовый | — |
| Абстрактный класс | △ | Средне-фиолетовый | `«abstract»` |
| Интерфейс | ◇ | Светло-фиолетовый | `«interface»` |
| Перечисление | ≡ | Зелёный | `«enumeration»` |

Подробнее — [docs/UML_TYPES.md](UML_TYPES.md)

## Работа с элементами

### Создание

**Из Toolbox** — кликни на нужный тип в левой панели.

**Кнопка тулбара** — "➕ Добавить класс" создаёт обычный класс.

### Редактирование

**Правая панель** — выбери элемент, редактируй прямо в панели Properties.

**Диалог** — кнопка "✏️ Редактировать" в тулбаре или правый клик → "✏ Редактировать класс".

#### Формат атрибутов
```
+name: str          # публичный
-age: int           # приватный
#salary: float      # защищённый
+count: int = 0     # со значением по умолчанию
```

#### Формат методов
```
+getName(): str
-setAge(age: int): void
+calculate(x: float, y: float): float
```

### Перемещение

Перетащи карточку мышью. Элементы автоматически привязываются к сетке (snap to grid).

### Удаление

- Выбери элемент → `Delete`
- Правый клик → "🗑 Удалить класс"
- Кнопка "Удалить" в панели Properties

## Связи

### Типы связей

| Тип | Линия | Стрелка | Описание |
|-----|-------|---------|----------|
| Ассоциация | Сплошная | Закрашенная | Простая связь |
| Наследование | Сплошная | Пустой треугольник | is-a |
| Композиция | Сплошная | Закрашенный ромб | Сильная часть |
| Агрегация | Сплошная | Пустой ромб | Слабая часть |
| Зависимость | Пунктирная | Открытая стрелка | Использует |
| Реализация | Пунктирная | Пустой треугольник | Реализует интерфейс |

### Создание связи

1. Наведи курсор на карточку — появятся точки привязки (фиолетовые кружки)
2. Зажми и потяни от точки привязки к другой карточке
3. Отпусти над точкой привязки цели

### Редактирование свойств связи

1. Кликни по линии связи (она выделится)
2. Нажми "🔗 Связи" в тулбаре
3. В диалоге настрой:
   - **Тип связи**
   - **Множественность источника** (1, 0..1, 0..*, 1..*, *)
   - **Множественность цели**
   - **Имя связи** (необязательно)

**Быстрая смена типа** — выбери связь, кликни на нужный тип в Toolbox.

## Генерация кода

1. Нажми **"⚡ Сгенерировать код"** в тулбаре или `Ctrl+G`
2. Выбери язык программирования
3. Просмотри сгенерированный код во вкладках
4. Нажми **"Экспорт файлов"** для сохранения

### Поддерживаемые языки

- **Python** — с `ABC`, `abstractmethod`, `Enum`, type hints
- **Java** — с модификаторами доступа, `interface`, `abstract`, `enum`
- **JavaScript** — ES6 классы
- **TypeScript** — с типизацией, `interface`, `abstract`, `enum`
- **C#** — с `interface`, `abstract`, `enum`

### Пример (Python)

```python
from abc import ABC, abstractmethod
from enum import Enum

class IDrawable(ABC):
    """Interface: IDrawable"""

    @abstractmethod
    def draw(self) -> None:
        raise NotImplementedError

class Shape(ABC):
    """Abstract class: Shape"""

    color: str

    def __init__(self):
        self.color = None

    @abstractmethod
    def draw(self) -> None:
        raise NotImplementedError

class Status(Enum):
    """Enumeration: Status"""
    ACTIVE = 1
    INACTIVE = 2
```

## Копирование и дублирование

| Действие | Клавиша | Описание |
|----------|---------|----------|
| Копировать | `Ctrl+C` | Скопировать выбранные карточки в буфер |
| Вставить | `Ctrl+V` | Вставить из буфера (со смещением +40px) |
| Дублировать | `Ctrl+D` | Создать копию прямо на месте (+30px смещение) |
| Выделить всё | `Ctrl+A` | Выделить все элементы на холсте |

Скопированные элементы получают суффикс `_copy` в имени.

## Экспорт проекта

`Ctrl+E` или меню Tools → Export Project

Создаёт готовую структуру папок проекта:
- Выбор языка и архитектуры (Simple, MVC, Layered, Clean)
- Конфигурационные файлы (requirements.txt, package.json, pom.xml и др.)
- README.md, .gitignore, тесты, CI/CD
- Предпросмотр структуры в реальном времени
