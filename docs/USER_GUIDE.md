## Первые шаги

### Запуск приложения

После установки запустите LogicCraft:

```bash
poetry run python -m src.logiccraft.main
```

### Интерфейс приложения

Главное окно состоит из:

- **Панель инструментов** (сверху) — основные действия
- **Рабочая область** (центр) — холст для диаграммы
- **Строка состояния** (снизу) — информация о текущем состоянии

## Работа с классами

### Создание класса

**Способ 1: Через панель инструментов**
1. Нажмите кнопку **"Add Class"**
2. Класс появится в центре экрана

**Способ 2: Двойной клик**
1. Дважды кликните на пустом месте
2. Класс создастся в месте клика

### Редактирование класса

**Способ 1: Контекстное меню**
1. Кликните правой кнопкой по классу
2. Выберите **"Edit"**

**Способ 2: Двойной клик**
1. Дважды кликните по карточке класса

**Способ 3: Панель инструментов**
1. Выделите класс (кликните по нему)
2. Нажмите **"Edit Selected"**

### Диалог редактирования

В диалоге редактирования вы можете изменить:

#### Имя класса
- Введите новое имя в поле "Class Name"
- Рекомендуется использовать PascalCase (например: `UserAccount`)

#### Атрибуты (свойства)
Формат: `[видимость]имя: тип [= значение]`

**Примеры:**
- `+name: str` — публичный атрибут
- `-age: int` — приватный атрибут  
- `#salary: float` — защищенный атрибут
- `+count: int = 0` — с значением по умолчанию

**Видимость:**
- `+` — public (публичный)
- `-` — private (приватный)
- `#` — protected (защищенный)

#### Методы
Формат: `[видимость]имя(параметры): возвращаемый_тип`

**Примеры:**
- `+getName(): str` — публичный метод
- `-setAge(age: int): void` — приватный метод
- `#calculateSalary(bonus: float): float` — защищенный метод
- `+toString(): str` — без параметров

### Перемещение классов

1. Кликните по классу и удерживайте левую кнопку мыши
2. Перетащите класс в нужное место
3. Отпустите кнопку мыши

**Примечание:** Позиция сохраняется автоматически для Undo/Redo.

### Удаление класса

**Способ 1: Контекстное меню**
1. Кликните правой кнопкой по классу
2. Выберите **"Delete"**

**Способ 2: Клавиша Delete**
1. Выделите класс
2. Нажмите клавишу **Delete**

**Способ 3: Панель инструментов**
1. Выделите класс
2. Нажмите **"Delete Selected"**

## Создание связей

### Типы связей

LogicCraft поддерживает следующие типы связей UML:

| Тип | Обозначение | Описание |
|-----|-------------|----------|
| **Association** | `---▷` | Простая ассоциация между классами |
| **Inheritance** | `---◁` | Наследование (is-a отношение) |
| **Composition** | `---♦` | Композиция (сильная связь, part-of) |
| **Aggregation** | `---◇` | Агрегация (слабая связь, has-a) |

### Создание связи

1. **Наведите курсор** на красную точку привязки на границе класса
2. **Нажмите и удерживайте** левую кнопку мыши
3. **Перетащите** курсор к другому классу
4. **Отпустите** кнопку мыши над точкой привязки целевого класса

**Точки привязки:**
- **Сверху** — top
- **Снизу** — bottom  
- **Слева** — left
- **Справа** — right

### Изменение типа связи

1. **Выделите связь** — кликните по линии
2. **Откройте свойства** — нажмите "Edit Connection" или правый клик → "Properties"
3. **Выберите тип** из выпадающего списка
4. **Нажмите OK**

### Удаление связи

1. **Выделите связь** — кликните по линии
2. **Удалите** — нажмите Delete или "Delete Selected"

## Сохранение и загрузка

### Сохранение диаграммы

**Способ 1: Меню File**
1. File → Save
2. Выберите место и имя файла
3. Нажмите "Сохранить"

**Способ 2: Горячая клавиша**
1. Нажмите **Ctrl+S**
2. Выберите файл

**Формат файла:** JSON (`.json`)

### Загрузка диаграммы

**Способ 1: Меню File**
1. File → Load
2. Выберите файл `.json`
3. Нажмите "Открыть"

**Способ 2: Горячая клавиша**
1. Нажмите **Ctrl+O**
2. Выберите файл

### Очистка диаграммы

1. File → Clear
2. Подтвердите действие

**Внимание:** Это действие нельзя отменить через Undo!

## Генерация кода

LogicCraft поддерживает автоматическую генерацию кода из UML диаграмм на 5 языках программирования.

### 🚀 Как генерировать код

1. **Создайте диаграмму** с классами, атрибутами и методами
2. **Нажмите кнопку "🚀 Generate Code"** в тулбаре или меню Tools
3. **Выберите язык** в диалоге генерации
4. **Настройте параметры** генерации
5. **Просмотрите код** во вкладках
6. **Экспортируйте** или скопируйте код

### 📋 Поддерживаемые языки

- **Python** (.py) — с type hints и абстрактными классами
- **Java** (.java) — с модификаторами доступа и наследованием  
- **JavaScript** (.js) — ES6 классы
- **TypeScript** (.ts) — с типизацией и интерфейсами
- **C#** (.cs) — с properties и модификаторами

### ⚙️ Настройки генерации

#### Режимы генерации
- **Один файл** — все классы в одном файле
- **Отдельные файлы** — каждый класс в своем файле

#### Горячие клавиши
- `Ctrl+G` — открыть диалог генерации кода

### 🎯 Диалог генерации кода

#### Основные элементы
1. **Выбор языка** — выпадающий список языков
2. **Режим генерации** — один файл или отдельные файлы
3. **Вкладки с кодом** — предпросмотр сгенерированного кода
4. **Информационная панель** — статистика генерации
5. **Кнопки действий** — экспорт, копирование, закрытие

#### Функции
- **💾 Экспорт файлов** — сохранение кода в выбранную папку
- **📋 Копировать код** — копирование текущей вкладки в буфер
- **🎨 Подсветка синтаксиса** — цветовое выделение кода
- **📊 Статистика** — количество файлов, строк, классов

### 🛠️ Советы по использованию

- Используйте **осмысленные имена** классов и методов

- Проверяйте **сгенерированный код** перед использованием

## Советы и трюки

### Навигация по диаграмме

- **Панорамирование** — зажмите среднюю кнопку мыши и двигайте
- **Масштабирование** — используйте колесо мыши с зажатым Ctrl
- **Выделение области** — кликните на пустом месте и тяните для выделения нескольких элементов

### Организация классов

1. **Группируйте связанные классы** рядом друг с другом
2. **Используйте наследование** для создания иерархий
3. **Размещайте базовые классы сверху**, производные — снизу
4. **Избегайте пересечения линий** для лучшей читаемости

### Именование

- **Классы** — PascalCase (`UserAccount`, `DatabaseManager`)
- **Атрибуты** — camelCase (`firstName`, `isActive`)
- **Методы** — camelCase (`getName()`, `calculateTotal()`)

### Производительность

- **Используйте Undo/Redo** вместо ручного восстановления
- **Сохраняйте часто** — диаграммы могут быть сложными
- **Группируйте изменения** — делайте несколько правок за раз

### Устранение проблем

**Связь не создается:**
- Убедитесь, что тянете от красной точки к красной точке
- Проверьте, что точки привязки видны (класс должен быть выделен)

**Класс не перемещается:**
- Кликните точно по карточке класса, не по тексту
- Убедитесь, что класс выделен (синяя рамка)

**Диаграмма не сохраняется:**
- Проверьте права доступа к папке
- Убедитесь, что указали расширение `.json`
