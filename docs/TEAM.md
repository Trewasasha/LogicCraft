# 👥 Команда LogicCraft

Познакомьтесь с командой разработчиков LogicCraft и их ролями в проекте.

## 🎯 Состав команды

### 🏗️ Саша (Architect)
**Роль:** Архитектор системы и DevOps

**Ответственность:**
- Ядро системы и общая архитектура
- Интеграция компонентов (PyQt6 + Pydantic)
- Кроссплатформенная сборка и развертывание
- CI/CD пайплайны и автоматизация
- Оптимизация производительности
- Управление зависимостями и версиями

**Основные достижения:**
- Разработка архитектуры MVC с разделением ответственности
- Настройка Poetry для управления зависимостями
- Оптимизация HistoryService (+30-50% производительности)
- Система сигналов/слотов для слабой связанности компонентов

**Технологии:** Python, PyQt6, Poetry, CI/CD, Architecture Design

---

### 🎨 Даша (Frontend Developer)
**Роль:** Разработчик пользовательского интерфейса

**Ответственность:**
- Дизайн и реализация GUI компонентов
- Интерактивные элементы (UML карточки, связи)
- Визуализация диаграмм и 2D графика
- Drag & Drop функциональность
- Пользовательский опыт (UX/UI)
- Система стилей и тем оформления

**Основные достижения:**
- Создание интерактивных UML карточек с drag & drop
- Реализация системы точек привязки для связей
- Разработка визуализации различных типов связей
- Централизованная система стилей (theme.py + style.qss)
- Контекстные меню и диалоги редактирования

**Технологии:** PyQt6, QGraphicsScene, CSS/QSS, UI/UX Design

---

### 🔧 Семён (Backend Developer)
**Роль:** Разработчик бэкенда и моделей данных

**Ответственность:**
- Pydantic модели данных (UMLDiagram, UMLNode, UMLConnection)
- Логика отношений между классами
- Сериализация и валидация данных
- Движок генерации кода (Python, Java, JavaScript)
- Бизнес-логика и алгоритмы
- Система валидации диаграмм

**Основные достижения:**
- Разработка полной модели данных UML с Pydantic
- Реализация генератора кода для 3 языков программирования
- Система валидации целостности диаграмм
- JSON сериализация с автоматической валидацией
- Алгоритмы обработки связей и зависимостей

**Технологии:** Python, Pydantic, JSON, Code Generation, Data Modeling

## 🤝 Принципы работы команды

### Разделение ответственности
- **Архитектура** — общая структура и интеграция
- **Frontend** — все что видит пользователь
- **Backend** — данные и бизнес-логика

### Коммуникация
- Еженедельные синхронизации прогресса
- Code review для всех изменений
- Общие стандарты кодирования
- Документирование архитектурных решений

### Технологический стек
- **Общий язык:** Python 3.13+
- **GUI:** PyQt6 (Даша)
- **Данные:** Pydantic (Семён)
- **Сборка:** Poetry (Саша)
- **Контроль версий:** Git + GitHub
