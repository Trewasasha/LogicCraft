# 🚀 Быстрый старт: Генерация кода

Пошаговое руководство по генерации кода из UML диаграмм в LogicCraft.

## 📋 За 5 минут

### Шаг 1: Создайте диаграмму
1. Запустите LogicCraft
2. Нажмите **"➕ Add Class"** в тулбаре
3. Создайте класс "User" с атрибутами:
   - `id: int` (private)
   - `name: str` (public)
   - `email: str` (public)
4. Добавьте методы:
   - `get_id(): int` (public)
   - `set_name(name: str): void` (public)

### Шаг 2: Генерируйте код
1. Нажмите **"🚀 Generate Code"** в тулбаре (или `Ctrl+G`)
2. Выберите язык программирования (например, Python)
3. Просмотрите сгенерированный код во вкладках

### Шаг 3: Экспортируйте код
1. Нажмите **"💾 Экспорт файлов"**
2. Выберите папку для сохранения
3. Готово! Код сохранен в файлы

## 🎯 Результат

Вы получите готовый код класса:

```python
"""Generated from UML Diagram: Untitled"""
from typing import List, Optional

class User:
    """Class generated from UML diagram"""

    # Attributes
    __id: int = 0
    name: str = ""
    email: str = ""

    def __init__(self):
        self.id = 0
        self.name = ""
        self.email = ""

    # Methods
    def get_id(self) -> int:
        pass

    def set_name(self, name: str) -> None:
        pass
```

## 🔧 Дополнительные возможности

### Множественные языки
Переключайтесь между языками одним кликом:
- Python → Java → JavaScript → TypeScript → C#

### Режимы генерации
- **Один файл** — все классы вместе
- **Отдельные файлы** — каждый класс в своем файле

### Связи между классами
Создавайте наследование:
1. Добавьте второй класс "Admin"
2. Создайте связь наследования: Admin → User
3. Код автоматически включит `extends`/наследование

## 💡 Советы

- **Указывайте типы данных** для лучшей генерации
- **Используйте видимость** (public/private/protected)
- **Создавайте связи** для автоматического наследования
- **Проверяйте код** перед использованием в проекте

## 🆘 Помощь

Если диаграмма пуста, появится сообщение:
> "Диаграмма пуста. Добавьте классы для генерации кода."

**Решение:** Создайте хотя бы один класс с помощью "➕ Add Class"
